更新
固件版本：—
固件升级前请拔掉 2.4G 接收器，并连接数据线确保设备处于有线模式再进行升级
  • ✅ 有线 USB：支持刷写（这是原厂驱动唯一的刷写路径）。
  • ❌ 2.4G 无线：不可行。接收器只能转发 64 字节配置报文，无法让键盘重新枚举成 Bootloader。
  • ❌ 蓝牙：不可行。且浏览器拿不到键盘的 HID 集合。

浏览器环境无法完成 USB 重新枚举与固件校验，因此本页面不提供刷写功能；请使用原厂工具在有线模式下升级。


        


        

          
IOT驱动设置

          
启用 IOT 驱动可以自动识别设备，支持有线、蓝牙和 2.4G 三种方式连接，灯效支持音乐律动和光影，支持社区分享功能、兼容更多浏览器。

          
本复刻版是纯 Web（WebHID）实现：不需要安装 IOT 后台服务，浏览器里点「连接」即可；
             音乐律动 / 光影 / 社区分享依赖本地服务与厂商服务器，网页版未包含。

            2.4G 接收器使用提示
            
这个接收器的厂商配置通道很敏感：连续 / 过快 / 过晚的读取都可能让它 stall（之后所有访问报错，
            表现就是「连上一会儿就断」）。所以本页面默认不做任何后台轮询，需要看状态请手动点下面的按钮。
