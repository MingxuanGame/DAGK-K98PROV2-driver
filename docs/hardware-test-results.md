## 3. 结论

* **配置读写**：灯效 / 侧灯 / 回报率 / 去抖 / 键盘选项 / 休眠 / 宏 / 三层按键矩阵 —— 有线与无线都能读、能写、写回原值后逐字节一致。
* **改键写入**：单键写入 → 读回 → 还原，整层 md5 与备份完全相同（有线 + 无线各验一次）。
* **协议**：复刻版发出的每一帧都与原厂驱动发出的帧逐字节一致（`docs/protocol-parity.md`）。
* **界面**：侧栏/顶部栏/底栏/键盘图/键帽/分类栏/按钮的尺寸与配色与原厂归档数值全部一致（`npm run test:ui`）。
* **测试**：45 单测 + 68 浏览器端到端 + 20 键盘页冒烟 + 14 预部署 + UI 对照 + 帧对照，全绿。

## 4. 结论之外的两点提醒

1. **2.4G 接收器的 `isCanRead` 标志不可靠**（应答已就绪却不置位）。驱动已改为"照读一次 + 校验回包"
   （`web/js/transport.js`），并加了模拟该情况的端到端回归用例。
2. **刷写固件**仍然只能在有线模式下用原厂工具做 —— 浏览器无法让键盘重新枚举成 Bootloader
   （原因见 `docs/upgrade.md`）。本复刻版不提供刷写。
